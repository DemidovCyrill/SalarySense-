# Словарь
| Термин | Значение |
|---|---|
| SDD | Spec-Driven Development: разработка по проверяемым спецификациям |
| SAD | Software Architecture Document: описание архитектуры |
| RAG | Генерация ответа с контекстом, найденным в базе знаний |
| Role | Профессия/подроль; не только семейство «Разработка» |
| Skill | Единица каталога, типизируется как знание/компетенция/технология/ответственность |
| Criterion | Наблюдаемый признак для оценки конкретного scope |
| Scope | Граница того, что заявлено или проверено |
| Evidence | Заявление или результат проверки; вид доказательства сохраняется |
| GradeProfile | Модель требований уровня для конкретной роли |
| Lead | Ответственность за решения/людей/процессы по выбранной модели; не просто балл теста |
| Coverage | Готовность каталога, критериев и проверок по роли |
| Snapshot | Неизменяемая версия набора данных |
| Match | Покрытие требований; не вероятность найма |
| Gross / Net | До / после налогов; unknown не смешивается с ними |
| ADR | Запись решения: контекст, альтернативы, выбор, последствия |
| Demo | Синтетические данные с явной отметкой |
| Acceptance criterion | Наблюдаемое условие приёмки функции |
