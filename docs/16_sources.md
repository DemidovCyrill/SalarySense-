# Источники и статус использования
Проверка публичных страниц: 16 октября 2026. Не копировались полные тексты стандартов. Ниже ссылки на первичные страницы; пригодность источника и лицензия конкретного файла проверяются перед импортом. Ссылки не являются комплектом лицензий на все внешние материалы.

| Источник | URL | Применение |
|---|---|---|
| GitHub Spec Kit | https://github.github.com/spec-kit/ | Структура spec→plan→tasks→implement→converge |
| arc42 | https://arc42.org/overview/ | Темы архитектурного описания; тексты документа собственные |
| C4 model | https://c4model.com/diagrams | Уровни архитектурных видов |
| OpenAPI 3.1.1 | https://spec.openapis.org/oas/v3.1.1.html | Версия API-контракта выбрана для совместимости, не заявлена как последняя |
| JSON Schema | https://json-schema.org/draft/2020-12 | Диалект схем в комплекте |
| ESCO | https://esco.ec.europa.eu/en/use-esco/download | Выгрузка каталога, не импортирована в комплект |
| Структура ESCO | https://esco.ec.europa.eu/en/structure-esco-downloadable-datasets | Связи URI, skills/occupations |
| O*NET | https://www.onetcenter.org/database.html | Дополнительный источник; CC BY 4.0 для указанных файлов с исключениями |
| Monzo | https://github.com/monzo/progression-framework | Публичные корпоративные критерии; repo отмечен MIT, проверять файл/версию |
