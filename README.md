# SalarySense

**Что хотим сделать:** сайт для людей из разных направлений IT. Человек выбирает роль, отмечает свои навыки и опыт, может пройти несколько коротких проверок и видит требования работодателей, предложения зарплат и подходящие вакансии. Сайт объясняет, что в профиле заявлено самим человеком, что проверено и чего пока неизвестно. По выбранной вакансии можно подготовить черновик письма.

Это студенческий проект команды. Сейчас здесь **документация и пустой каркас**, а не готовый сайт: интерфейс, расчёты, подключение вакансий, тесты и запуск ещё предстоит сделать.

## Как читать статусы

**Подтверждено** — пользователь прямо выбрал направление продукта: все направления IT, карта навыков, короткие проверки, рынок и вакансии, отдельный учёт заявленного и проверенного, RAG для объяснения критериев. **Предложено** — конкретный способ реализации, например формула или порог размера зарплатной выборки. **Открыто** — данных для решения ещё нет. Ни один из этих статусов не означает «реализовано» или «проверено».

QA в документах встречается как пример. Продукт не ограничивается QA. При этом полнота данных по каждой роли должна быть видна: нельзя обещать подтверждённую оценку там, где ещё нет проверенных критериев или вопросов.

В этом объёме нет парсинга резюме, рекомендаций учебных материалов, автоматической отправки откликов и публичного запуска. Суммы из вакансий — рыночный ориентир, не обещание личной зарплаты. До реализации и проверки источников нельзя показывать выдуманные вакансии, ссылки или результаты как реальные.
