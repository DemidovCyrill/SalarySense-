# SalarySense

**Что хотим сделать:** сайт для людей из разных направлений IT. Человек выбирает роль, отмечает свои навыки и опыт, может пройти несколько коротких проверок и видит требования работодателей, предложения зарплат и подходящие вакансии. Сайт объясняет, что в профиле заявлено самим человеком, что проверено и чего пока неизвестно. По выбранной вакансии можно подготовить черновик письма.

Это студенческий проект команды. В репозитории есть **рабочий локальный фронтенд на демоданных** и документация для будущего бэкенда. Демо включает профиль, навыки, квизы, уровни, рынок, вакансии, письма, базу знаний и редакцию материалов.

## Запустить демо

Из корня репозитория запустите команду с Node.js 22 или новее.

```powershell
node app/frontend/demo/server.mjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). На обзоре нажмите «Посмотреть пример разбора», чтобы проверить требования вакансии и совпадение с учебным профилем Frontend-разработчика. Начать с пустого профиля можно через «Все разделы» → «Настройки» → «Удалить профиль». Сессии хранятся в памяти локального сервера и сбрасываются при его остановке.

## Как читать статусы

**Подтверждено** — пользователь прямо выбрал направление продукта: все направления IT, карта навыков, короткие проверки, рынок и вакансии, отдельный учёт заявленного и проверенного, RAG для объяснения критериев. **Предложено** — конкретный способ реализации, например формула или порог размера зарплатной выборки. **Открыто** — данных для решения ещё нет. Ни один из этих статусов не означает «реализовано» или «проверено».

QA в документах встречается как пример. Продукт не ограничивается QA. При этом полнота данных по каждой роли должна быть видна: нельзя обещать подтверждённую оценку там, где ещё нет проверенных критериев или вопросов.

Для первой рабочей версии RAG согласованы подсказки по пробелам в навыках и подготовка черновиков вопросов для коротких проверок. Команде предстоит подобрать и проверить датасеты. [Требования к источникам и проверке](spec/tech/rag.md)

Парсинг резюме, автоматическая отправка откликов и публичный запуск находятся за рамками проекта. Суммы из вакансий — рыночный ориентир, не обещание личной зарплаты. До реализации и проверки источников нельзя показывать выдуманные вакансии, ссылки или результаты как реальные.
