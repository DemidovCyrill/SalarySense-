# SalarySense

Помощник по зарплатам в IT: ищет ответы в датасете глобальных tech-зарплат и формирует понятные ответы с помощью LLM.

## Запуск

python -m app

## Основной сценарий

Пользователь задаёт вопрос про зарплату (роль, грейд, локация) -> система находит релевантные записи в датасете (BM25) -> LLM формирует ответ с цифрами и источником.
