# Объяснение через RAG
Статус: Draft for review · версия 1.0

## Цель
Извлекать только published/allowed критерии, формировать проверяемые claims.

## Связь
Требования: FR12, FR14. Проверки: T12, T13, T17.

## User story
Как пользователь, я хочу получить понятный результат этой функции и видеть, какие данные его подтверждают, чтобы выбирать дальнейшие действия.

## Acceptance criteria
- AC1: Подготовить content manifest и review pipeline. Проверка описана в связанных тестах и общем контракте.
- AC2: Собрать фильтрованный индекс и baseline retrieval. Проверка описана в связанных тестах и общем контракте.
- AC3: Добавить generation schema и validation. Проверка описана в связанных тестах и общем контракте.
- AC4: Сравнить no-RAG/baseline/RAG на test split. Проверка описана в связанных тестах и общем контракте.

## Исключения
Нет данных → явное пустое/недостаточное состояние. Недоступный внешний сервис → контролируемый отказ без выдуманного результата. Несовместимая версия → conflict/stale, а не молчаливая подмена.

## Out of scope
Функции, не перечисленные в FR, не добавляются по инициативе генератора кода. Нет автоматической публикации или отправки откликов.
