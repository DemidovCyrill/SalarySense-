# Короткие проверки
Статус: Draft for review · версия 1.0

## Цель
Проверка привязана к навыку, scope и frozen bank_version; ключи только на сервере.

## Связь
Требования: FR05, FR06. Проверки: T03, T15, T16.

## User story
Как пользователь, я хочу получить понятный результат этой функции и видеть, какие данные его подтверждают, чтобы выбирать дальнейшие действия.

## Acceptance criteria
- AC1: Создать public DTO вопроса. Проверка описана в связанных тестах и общем контракте.
- AC2: Реализовать state machine попытки. Проверка описана в связанных тестах и общем контракте.
- AC3: Сохранить ответы и идемпотентное завершение. Проверка описана в связанных тестах и общем контракте.
- AC4: Показать результат и ограничения. Проверка описана в связанных тестах и общем контракте.

## Исключения
Нет данных → явное пустое/недостаточное состояние. Недоступный внешний сервис → контролируемый отказ без выдуманного результата. Несовместимая версия → conflict/stale, а не молчаливая подмена.

## Out of scope
Функции, не перечисленные в FR, не добавляются по инициативе генератора кода. Нет автоматической публикации или отправки откликов.
