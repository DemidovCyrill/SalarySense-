# RAG

## Корпус

Датасет глобальных tech-зарплат (Kaggle: Global Tech Salary Dataset). Записи: год, грейд, должность, тип занятости, зарплата в USD, удалёнка, локация, размер компании.

## Индексация

BM25 по записям датасета. Каждая запись — отдельный документ с полями как текстом.

## Поиск

По запросу пользователя возвращаются top-k релевантных записей.

## Контекст для LLM

Найденные записи + вопрос пользователя -> промпт для LLM.

## Benchmark

Набор вопросов с эталонными ответами/диапазонами для оценки качества поиска и ответов.
