# Сценарии

## Основной сценарий

1. Пользователь открывает чат-интерфейс
2. Пишет вопрос (например: сколько получает Data Scientist мидл-уровня на удалёнке в Европе?)
3. Система ищет релевантные записи в датасете (BM25)
4. LLM формирует ответ с цифрами на основе найденных записей
5. Пользователь видит ответ и ссылку на источник

## Сценарий: сравнение зарплат

1. Пользователь спрашивает: кто больше получает — DevOps или Backend-разработчик в США?
2. Система находит записи по обеим ролям
3. LLM формирует сравнительный ответ с медианами и диапазонами
