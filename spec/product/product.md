# Продукт

## Пользователь

Студент, соискатель или HR-специалист, интересующийся зарплатами в IT.

## Задача

Помочь пользователю получить оценку зарплаты по заданным параметрам (роль, грейд, локация, формат работы) на основе реальных данных.

## Описание

Сервис использует датасет глобальных tech-зарплат. Пользователь задаёт вопрос в чат-интерфейс, система ищет релевантные записи через BM25 и формирует ответ с помощью LLM, указывая источник данных.
