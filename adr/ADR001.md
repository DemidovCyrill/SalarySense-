# ADR001: Модульный монолит
Дата: 2026-10-16
Статус: Proposed (продуктовый охват всех IT уже Confirmed).

## Контекст
Малая команда и срок; нужен один набор правил.

## Решение
Один backend с доменными модулями, отдельный UI и worker из той же кодовой базы.

## Альтернативы
Микросервисы: накладные расходы; полностью клиентский app: не защищает ключи и вопросы.

## Последствия
Меньше инфраструктуры; требуется контроль границ модулей.

## Проверка / пересмотр
Проверить в соответствующих FR и тестах. Пересмотреть при изменении нагрузки, команды, бюджета или качества данных. Утверждающий и дата принятия заполняются командой, не выдуманы.
